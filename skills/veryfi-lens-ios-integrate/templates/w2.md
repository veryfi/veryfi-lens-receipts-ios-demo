# W-2

Pod `VeryfiLens-W2`. No dedicated SPM repo. Do not install `veryfi-lens-spm`.

Public installation URL was not fetched. **Unconfirmed** docs page. Pod name is `VeryfiLens-W2`.

Cloud extraction. `w2` is not an `.inApp` type. The document detector route used for `w2` is the page detector (`RemoteModelConditions` comment: `ImageProcessor.Mode` routes `w2` with receipts and bank statements to `DocumentDetectorHelper`). That comment is about remote-model download rules compiled only in the Remote Models flavor. It is still the type list those rules use. Whether the W-2 binary’s bundled model file has a different name is **Unconfirmed**.

Client settings type: `VeryfiLensSettings()`. Do not use `VeryfiLensW2Settings`. The Demo subclass turns `moreMenuIsOn` on. This template keeps the menu off, matching the tax recipe and the menu footgun.

## Permissions

| Key | When |
|-----|------|
| `NSCameraUsageDescription` | Camera |
| `NSPhotoLibraryUsageDescription` | Gallery in this recipe |
| `NSPhotoLibraryAddUsageDescription` | only if gallery backup is on. This template sets it false |
| `NSLocationWhenInUseUsageDescription` | only if location is on. This template sets it false |

Files import: `browseIsOn` is set, and `moreMenuIsOn` is false, so the More → Browse row is hidden. Use `showDocumentBrowser(in:)` or set `showBrowserButton = true` for a camera Files button. This template uses gallery plus the standalone browser when the host calls it. It does not turn the More menu on just to expose Browse.

Single-page form: stitch stays off. A multi-page W-2 packet is **Unconfirmed** as a stitch story. If the host must send several pages, raise `packageMaxScans` (default is already 10) and decide stitch versus separate packages explicitly. This template does not turn stitch on.

## Lifecycle and presentation

```swift
let credentials = VeryfiLensCredentials(
    clientId: "<clientId>",
    username: "<username>",
    apiKey: "<apiKey>",
    url: "https://api.veryfi.com"
)

VeryfiLens.shared().delegate = self
VeryfiLens.shared().configure(with: credentials, settings: settings) { success in
    DispatchQueue.main.async {
        guard success else { return }
        VeryfiLens.shared().showCamera(in: self)
    }
}
```

Gallery: `VeryfiLens.shared().showGallery(in: self)` instead of the camera, still after configure. SwiftUI: `.veryfiLensFullScreenCover` / `.veryfiLensSheet` with `.camera` or `.gallery`. One path.

`uploadImages(paths:)` is valid after configure and uses cloud extraction. The document type is the first `documentTypes` entry, `w2`.

## Callbacks

Standard `VeryfiLensDelegate`. Success `status` `"done"` is the cloud W-2 extract. API field names inside `data` are not listed in this pack. Do not invent box numbers or JSON keys.

`document_type` is `w2` when the package type is set.

Image paths arrive on `veryfiLensUpdate`. Copy them if local auto-delete stays at the default true.

`veryfiLensClose` is the UI session ending, including cancel with no success.

## Conflicts and do-not

- Do not set `documentTypes` to `w9` on this binary. Use [w9.md](w9.md).
- Do not set `.inApp`.
- Do not set `stitchIsOn` true for the single-page recipe.
- Do not turn `moreMenuIsOn` on to reveal `browseIsOn`. Present `showDocumentBrowser(in:)` or set `showBrowserButton`.
- Do not install `veryfi-lens-spm`.
- Do not use `VeryfiLensW2Settings`.
- Do not promise local field detection. `documentFieldsToDetect` needs entitlement and the Field Detection or Remote Models flavor.
