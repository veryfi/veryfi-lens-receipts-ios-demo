# W-9

Same UI SDK pattern as [W-2](w2.md), with pod `VeryfiLens-W9` and `documentTypes = ["w9"]`.

No dedicated SPM repo. Do not install `veryfi-lens-spm`.

Public installation URL was not fetched. **Unconfirmed** docs page. Pod name is `VeryfiLens-W9`.

Cloud extraction. `w9` is not an `.inApp` type. `RemoteModelConditions` lists `w9` with the page document detector types (`receipt`, `long_receipt`, `invoice`, `w2`, `bank_statement`, and the rest of that set). That file is compiled for Remote Models. The W-9 flavor is a separate binary. Exact bundled model filename is **Unconfirmed**.

Client settings type: `VeryfiLensSettings()`. Do not use `VeryfiLensW9Settings`.

## Permissions

| Key | When |
|-----|------|
| `NSCameraUsageDescription` | Camera |
| `NSPhotoLibraryUsageDescription` | Gallery in this recipe |
| `NSPhotoLibraryAddUsageDescription` | only if gallery backup is on. This template sets it false |
| `NSLocationWhenInUseUsageDescription` | only if location is on. This template sets it false |

`browseIsOn` is true and `moreMenuIsOn` is false, so More → Browse is hidden. Call `showDocumentBrowser(in:)` for Files, or set `showBrowserButton` if the camera should show a Files button.

W-9 is treated as a single-page form in the tax recipe (`stitchIsOn` false). Multi-page behavior is **Unconfirmed**. `packageMaxScans` defaults to 10 if the host later allows more than one image. This template does not raise or lower it.

## Lifecycle and presentation

```swift
let credentials = VeryfiLensCredentials(
    clientId: "<clientId>",
    username: "<username>",
    apiKey: "<apiKey>",
    url: "https://api.veryfi.com"
)

VeryfiLens.shared().delegate = self
VeryfiLens.shared().configure(with: credentials, settings: settings) { success in
    DispatchQueue.main.async {
        guard success else { return }
        VeryfiLens.shared().showCamera(in: self)
    }
}
```

Alternate paths after the same configure: `showGallery(in:)`, `showDocumentBrowser(in:)`, or SwiftUI `.veryfiLensFullScreenCover` / `.veryfiLensSheet`. One path at a time.

`uploadImages(paths:)` uses cloud extraction and the first document type, `w9`.

## Callbacks

Standard `VeryfiLensDelegate`. Success `status` `"done"` is the cloud extract. This pack does not list W-9 API field names. Read `data` as the Process a Document body and map fields from the API docs the customer’s account uses. Do not invent keys.

`document_type` is `w9` when the package type is set.

`veryfiLensUpdate` carries file paths. Copy them while local auto-delete is still the default true, or set `autoDeleteLocalResourcesAfterProcessing = false` and delete later.

`veryfiLensClose` is not success. A cancel closes with no `"done"` payload.

`veryfiLensError` `msg` `invalid_credentials` means an empty credential field. Set the delegate before `configure` so that error is delivered.

## Conflicts and do-not

- Do not set `documentTypes` to `w2` on the W-9 binary.
- Do not set `.inApp` or `ocrType`.
- Do not set `stitchIsOn` true for this single-page recipe.
- Do not enable the More menu only to honor `browseIsOn`.
- Do not install the Full SPM package.
- Do not use `VeryfiLensW9Settings`.
- Do not set `anyDocumentType` or `cameraProcessingMode`.
